S/4HANA Mobility

We develop end-to-end custom Fiori applications and extend standard Fiori applications, from Fiori 1.0 onwards, in both Eclipse and SAP Cloud Platform (formerly HCP), and deliver them in Embedded and Central Hub scenarios.

Our Fiori applications run on desktop and on Android and iOS mobile devices, using native device features such as the camera for barcode and QR code scanning and for capturing images. We deliver Reports, Approvals and Dashboards.
